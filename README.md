# VSCO Growth Audit

**Live → https://eddieatadapty.github.io/vsco-flow-rebuild/**

Five ideas to turn more VSCO users into subscribers, each built into a clickable version of VSCO's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Ask what brought them, then open on it | +10–20% CR to purchase |
| 02 | One edit before the account and the price | +10–20% CR to purchase |
| 03 | Your 4.7 and the photographer stories, before the price | +5–10% CR to purchase |
| 04 | Make the yearly saving impossible to miss | +10–15% ARPU, more people on yearly |
| 05 | Catch the people who close the paywall | +10–15% ARPU |

Every price, rating and feature comes from VSCO's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for VSCO. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
